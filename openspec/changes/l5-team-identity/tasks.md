# L5 — tasks

Nothing in this lot is implemented, and nothing in it may be started without an
explicit authorisation to introduce an account or an identity.

- [ ] A person is created locally, is stable, and can be exported and wiped.
- [ ] Consent is per purpose, revocable, and its history is readable.
- [ ] A document is shared to a named person, and to nobody else.
- [ ] A refusal is explicit, and never leaves a silent half-share behind.
- [ ] A contribution is attributed to the person who made it, on the object they
      touched.
- [ ] Removing a person removes their access, and says what history remains.

## Blocked, and honestly so

TEAM is a target, not a permission. It requires a decision on identity that the
user has not made, and the answer changes the format of every shared document.
Starting code before that answer would be guessing at the schema.
