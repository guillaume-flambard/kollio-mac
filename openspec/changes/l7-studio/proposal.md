# L7 — I make something out of it

## Why

An idea that stays an idea is a note. Studio turns the document into an artefact
the person can use, without leaving the app or losing the link back to why.

## What changes

- An object becomes presentable: a document, a deck, an export.
- Composition built from the document's own objects, never from a duplicate.
- Editing in place, with the provenance visible while editing.
- Personal templates, owned by the person, never shared by default.

## What it does not change

Everything authored is the user's own words. Studio never paraphrases authored
text into something else, per invariant 8.
