# L9 — the outside world, deliberately

## Why

Some ideas are only useful if they can leave the tool. That is a boundary
decision, not a feature, and it is the last lot on purpose.

## What changes

- Export to a human format, owned by the person.
- A public presentation of a document, with the authored text intact.
- Documented boundaries on what is never shared, whatever is configured.

## What it does not change

No marketplace, no account, no upload. The lot is scoped to leaving under the
person's control.
